# Security Policy

## Supported Versions

We only support the latest version of EchoGen during the Hackathon phase.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of EchoGen seriously. If you find a vulnerability, please report it following these steps:

1. **Do not open a public GitHub Issue.**
2. Send a detailed report to the project maintainers (contact details available on the team's profile).
3. Include as much information as possible:
   - Type of vulnerability (e.g., SQL injection, XSS, RPC exploit).
   - Location of the vulnerability.
   - Potential impact.
   - Steps to reproduce.

We will acknowledge your report within 48 hours and work with you to resolve the issue before making it public.

---

*Note: Since EchoGen handles on-chain signatures and API keys (stored locally in the browser), we prioritize client-side security and data privacy.*
